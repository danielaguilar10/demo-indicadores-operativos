# Demostración de indicadores operativos

Una muestra independiente de una interfaz de indicadores de producción, calidad y mantenimiento. Se creó para portafolio a partir de categorías generales observadas en un sistema empresarial.

**Todos los datos son ficticios.** No contiene bases de datos, credenciales, información de clientes, nombres de empresa, registros operativos ni código del sistema original. Es una maqueta estática, no una copia funcional del producto de producción ni una integración con JD Edwards.

## Uso

Abre `index.html` en un navegador. No requiere instalación ni conexión a Internet.

## Alcance

Incluye tarjetas de resumen, un gráfico de barras, un gráfico de distribución y un indicador de calidad. Las cifras se eligieron únicamente para ilustrar la interfaz.
